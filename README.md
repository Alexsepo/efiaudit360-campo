# EfiAudit360 · Campo

App web instalable (PWA) para capturar fotos, audio, vídeo, archivos y notas en una visita, sin conexión. Solo contiene el código de la aplicación: los datos de las visitas se quedan en el móvil de quien la usa y nunca se suben a este repositorio.

Código fuente de referencia y pruebas: repositorio privado del proyecto (`docs/CAMPO.md`).
